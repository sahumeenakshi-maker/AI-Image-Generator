# AI Image Generator

A Flask-based AI Image Generator that generates images from text prompts using RapidAPI.

## Features

- Generate AI images from text prompts
- Flask web application
- HTML frontend
- API integration using Requests
- User-friendly interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Requests
- RapidAPI

## Project Structure

AI GENERATOR/
│
├── app.py
├── templates/
│ └── home.html
└── AI IMAGE GENERATOR.ipynb

## Installation

1. Clone the repository

```bash
git clone https://github.com/sahumeenakshi-maker/AI-Image-Generator.git
```

2. Install dependencies

```bash
pip install flask requests
```

3. Run application

```bash
python app.py
```
